## نظرة عامة

**مكالمة وهمية** تطبيق أندرويد مفتوح المصدر يحاكي مكالمة هاتفية واردة في الوقت الذي تختاره، باسم ورقم متصل تحددهما، مع صوت اختياري يُشغَّل عند الرد. مفيد للخصوصية والترفيه والعروض التوضيحية والاختبار.

- يعمل على **أندرويد 11 (API 30) حتى أندرويد 17 (API 37)**
- **عربي وإنجليزي** بواجهة كاملة الاتجاهين (RTL / LTR)
- **بدون إعلانات، ولا تحليلات، ولا تتبع، ولا جمع بيانات.** الإنترنت يُستخدم فقط للتحقق من التحديثات على GitHub.

## المميزات

- **تجربة مكالمة حقيقية** — المكالمات تُنشأ عبر إطار عمل Telecom في أندرويد وترن في تطبيق الهاتف الخاص بالنظام (بعد تفعيل حساب «مكالمة وهمية» مرة واحدة من إعدادات النظام). إذا لم يكن الحساب مفعّلًا، يتحول التطبيق تلقائيًا إلى شاشة المكالمة الخاصة به بملء الشاشة. التفاصيل والحدود في [docs/CALL_ENGINE.md](docs/CALL_ENGINE.md).
- **جدولة مرنة** — رنّ الآن، أو بعد مهلة، أو في وقت محدد بدقة باستخدام المنبّهات الدقيقة. المكالمات المجدولة تبقى بعد إعادة تشغيل الجهاز.
- **صوت عند الرد** — اختر أي ملف صوتي ليُشغَّل عبر مسار الصوت الخاص بالمكالمات عند الرد.
- **سجل المكالمات** — تُسجَّل كل مكالمة وهمية (تم الرد / رفض / اكتملت).
- **إعدادات مسبقة** — حتى 5 إعدادات سريعة، متاحة أيضًا كاختصارات في شاشة التطبيقات وبلاطات في الإعدادات السريعة.
- **واجهة أتمتة** — شغّل المكالمات من Tasker أو MacroDroid أو ADB.
- **تحديثات من داخل التطبيق** — يفحص إصدارات GitHub، يعرض ملاحظات الإصدار بالعربية والإنجليزية، ينزّل ملف APK الجديد، يتحقق من بصمة SHA-256، ويثبّته فقط عند الضغط. ويمكنك دائمًا فتح صفحة GitHub مباشرة.
- **تصميم عصري** — Material 3 بثيم عنابي مخصص، ووضع فاتح وداكن، ومقدمة متحركة قصيرة تحترم إعدادات الحركة في النظام.

## التثبيت

1. نزّل ملف `fake-call-vX.Y.apk` من [صفحة الإصدارات](https://github.com/mgnegypt/fake-call/releases).
2. افتحه واسمح بالتثبيت من المتصفح أو مدير الملفات إذا طلب أندرويد ذلك.
3. افتح التطبيق، واختياريًا فعّل خيار **مكالمة وهمية** من *الإعدادات ← التطبيقات ← التطبيقات الافتراضية ← تطبيق الهاتف / حسابات الاتصال* لتَرِنّ المكالمات في تطبيق الهاتف الخاص بالنظام.

## واجهة الأتمتة (Automation API)

يمكن لـ Tasker أو MacroDroid أو ADB تشغيل مكالمة عبر بثّ (broadcast):

| | |
|---|---|
| **الإجراء (Action)** | `com.mgneg.fakecall.action.TRIGGER` |
| **المعاملات (Extras)** | ‏`caller_name` (نص)، ‏`caller_number` (نص)، ‏`delay` (رقم صحيح بالثواني) |

أي معامل ناقص يُستبدل بقيمك الافتراضية المحفوظة.

</div>

```bash
adb shell am broadcast \
  -a com.mgneg.fakecall.action.TRIGGER \
  --es caller_name "Mom" \
  --es caller_number "+201001234567" \
  --ei delay 10
```

## شرح الأذونات

| الإذن | السبب |
|---|---|
| حالة الهاتف (`READ_PHONE_STATE`) | تسجيل حساب Telecom والاستعلام عنه |
| جهات الاتصال (`READ_CONTACTS`) | اختيار المتصل من جهات الاتصال (يُستخدم فقط عند فتح منتقي جهات الاتصال، ولا يُرفع أي شيء) |
| المنبّهات الدقيقة | الرنين في الوقت المجدول بالضبط |
| الإشعارات (+ ملء الشاشة) | عرض المكالمة الواردة فوق شاشة القفل (الواجهة البديلة) |
| تثبيت الحزم | تثبيت التحديثات التي تؤكدها بنفسك |
| الإنترنت | فحص التحديثات من إصدارات GitHub فقط |
| اكتمال الإقلاع | إعادة جدولة المكالمات المعلّقة بعد إعادة التشغيل |
| استثناء توفير البطارية | منع تأخير المكالمات المجدولة أو إيقافها بسبب توفير البطارية (يُطلب من داخل التطبيق ولا يُفرض أبدًا) |
| إعدادات الصوت (`MODIFY_AUDIO_SETTINGS`) | تشغيل الصوت عبر مسار المكالمات عند الرد |

## البناء من المصدر

**المتطلبات:** JDK 17، وحزمة Android SDK ‏`android-37.0` مع build-tools ‏`37.0.0`، وGradle 9.8.2 (عبر الـ wrapper).

</div>

```bash
./gradlew :app:assembleDebug        # بناء تجريبي
./gradlew :app:testDebugUnitTest    # اختبارات الوحدة
./gradlew :app:assembleRelease      # بناء الإصدار (يحتاج متغيرات التوقيع)
```

<div dir="rtl">

يُقرأ توقيع الإصدار من متغيرات البيئة (لا ترفع الأسرار أبدًا): ‏`RELEASE_STORE_FILE` و`RELEASE_STORE_PASSWORD` و`RELEASE_KEY_ALIAS` و`RELEASE_KEY_PASSWORD`. في CI تأتي من GitHub Secrets، راجع [`.github/workflows/release.yml`](.github/workflows/release.yml). إصدارات المكتبات مثبّتة على أحدث النسخ المستقرة وموثّقة في [docs/VERSIONS.md](docs/VERSIONS.md).

## الخصوصية

التطبيق لا يجمع أي بيانات. جهات الاتصال والإعدادات المسبقة والسجل والإعدادات لا تغادر جهازك أبدًا. الطلبات الوحيدة عبر الشبكة هي فحص التحديثات من `api.github.com`، ويمكنك تجاهلها — فالتطبيق يعمل بالكامل بدون إنترنت.

## الاستخدام المسؤول

التطبيق مخصص للخصوصية والترفيه والعروض التوضيحية والاختبار. من فضلك لا تستخدمه لخداع أو مضايقة أو إيذاء أي شخص، أو لمخالفة أي قانون. أنت المسؤول عن طريقة استخدامك له.
